# Code of Conduct

## Our Commitment

We are committed to creating a welcoming, respectful, and collaborative environment for everyone contributing to this project.

---

## Expected Behavior

Contributors should:

- Be respectful and professional
- Provide constructive feedback
- Focus on technical discussions
- Respect different viewpoints
- Help others learn and improve

---

## Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment
- Personal attacks
- Discriminatory comments
- Offensive language
- Deliberate disruption of discussions

---

## Reporting Issues

If you experience or observe unacceptable behavior, please report it by opening an issue or contacting the repository maintainer.

---

## Scope

This code of conduct applies to:

- Issues
- Pull requests
- Discussions
- Code reviews
- Community interactions
